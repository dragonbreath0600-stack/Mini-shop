Mini-Shop сервис

Описание:
Проект представляет собой систему управления небольшим магазином:
- Каталог товаров
- Управление заказами
- Учёт покупок
- Статистика продаж
- Аналитика и отчёты
- Интеграция с платёжными системами

Структура проекта:
- products.md - каталог товаров
- orders.md - система заказов
- api-plan.md - план API
- project-notes.md - заметки по проекту

Технологии:
- Git для контроля версий
- Markdown для документации
