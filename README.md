Mini-Shop сервисъ
Проект представляет собой систему для управления небольшим магазином:
- Каталог товаров
- Управление заказами
- Учёт покупок
- Статистика продаж

Структура проекта:
- `products.md` - каталог товаров
- `orders.md` - система заказов
- `api-plan.md` - план API
- `project-notes.md` - заметки по проекту

Технологии:
- Git для контроля версий
- MarkDown для документации
